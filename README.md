Search for books by title or add them yourself. Choose reading days and a daily page goal or finish date. hon updates your schedule as your list, pace, and progress change.

Read books one at a time or split daily pages across several. Reorder books and edit page counts. Books appear as colored spines that expand to show their covers.

Export the daily reading plan as an `.ics` file or copy a fixed calendar feed URL. Each all-day event shows the book and its exact page target for that day.
